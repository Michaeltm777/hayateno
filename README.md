# کلیسای حیات نو — پیش‌نمایش

دموی دوزبانه وب‌سایت. زبان پیش‌فرض فارسی است (`/fa`) و انگلیسی در `/en` قرار دارد. باز کردن `/` به فارسی می‌رود.

```bash
npm run dev
```

سپس در مرورگر `http://localhost:3000` را باز کنید.

این نسخه نمایشی است: فرم تماس ذخیره نمی‌شود و پخش زنده وصل نیست. اگر بعداً پایگاه داده لازم شود، MySQL با `mysql2` استفاده می‌شود، بدون Prisma.
